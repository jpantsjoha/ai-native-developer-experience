description: Pursue an agreed goal to a working outcome without waiting, using the get-it-done skill
---

Load the `get-it-done` skill from this plugin and follow it exactly. Scope: the goal, epic or roadmap objective named in the arguments (or the current agreed plan).

$ARGUMENTS

Authority does not change because a command was run: the skill's stop-list, independent
review and the project's own controls still apply.
