# Privacy Policy

**Effective date:** 2026-07-20

`join-the-team` is an open-source operating-model and skill plugin. It does not
collect, transmit, sell, or share personal data, usage telemetry, prompts, source
code, or analytics on its own.

The plugin consists of local instructions, configuration, and validation assets.
When a user installs or invokes it, any information handled by an AI harness,
model provider, repository host, or tool integration is governed by that service's
settings and privacy policy, and by the user's own choices and credentials. The
plugin does not add a separate data collection service or remote endpoint.

The project may receive information that a contributor deliberately provides in a
public GitHub issue, pull request, discussion, or other public repository activity.
That information is handled through GitHub and remains subject to GitHub's terms
and privacy policy.

For privacy questions, open a GitHub issue in this repository. Changes to this
policy will be published in this document with an updated effective date.
